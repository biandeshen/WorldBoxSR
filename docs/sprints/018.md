# Sprint 018 — Isolate founder-cohort synchronization in grazer mortality failure

Status: **active** (#112)

## Goal

Test whether Sprint 017's carrying-pressure extinction is primarily caused by an artificially synchronized founder cohort before inventing a different mortality curve.

This sprint is research-only. It does not add runtime senescence, lifespan state/config/events, snapshot changes, or retune reproduction/resources/encounters.

## Fixed ecology

Keep authoritative behavior unchanged:

- grazer reproduction partner search radius 3;
- each parent's local vegetation measurement radius 1;
- local vegetation threshold 0.50;
- birth chance `0.001`;
- current maturity/health/hunger/cooldown/stable-pairing/keyed-random semantics;
- no sequential RNG;
- no global population target.

Research mortality remains the same failed Sprint 017 hard keyed-uniform **12–18 year lifespan**.

## Single variable

Compare founder starting-age structure only:

1. **synchronized control** — every founder starts at exactly age 2;
2. **heterogeneous cohort** — founder age is deterministically/keyed over **0–6 years** from `world.seed + creatureId`.

The 0–6y range is pre-registered. Do not search other founder-age ranges in this sprint.

All founders remain below the minimum 12y research lifespan at initialization. Spawn locations, counts, hunger, health, landscape, reproduction, and lifespan endpoints are otherwise unchanged.

## Matrix

- 24×24 creature-only worlds;
- seeds `1/4/9`;
- founder densities `100/200`;
- synchronized age2 vs heterogeneous age0–6;
- 60-year horizon;
- 30-day vegetation sampling;
- 5-year checkpoints.

Research ordering remains:

`environment regeneration → grazer action → day increment → research senescence → authoritative reproduction`

## Measurements

For each run record:

- living population trajectory and extinction/minimum;
- creature births;
- starvation vs research old-age deaths;
- founder extinction timing;
- births after original founders disappear;
- replacement-parent births;
- vegetation utilization/minimum;
- founder and living age summaries;
- exact sequential RNG fingerprint.

## Decision rule

This issue answers only whether founder synchronization is a major cause.

### Supports synchronization hypothesis

The heterogeneous cohort must materially restore multi-generation persistence on **all seeds and both densities**, while the synchronized control reproduces Sprint 017's failure.

### Rejects synchronization as sufficient

If heterogeneous founders still go extinct, remain tiny non-recovering tails, or rescue only a subset of landscapes/densities, stop founder-age tuning. The next mortality gate must change the mortality curve itself, e.g. a gradual age-dependent hazard.

No post-hoc founder-age range search is allowed.

## Non-goals

- no runtime old age;
- no different lifespan endpoints;
- no gradual hazard in this same sprint;
- no birth-chance/resource-threshold/partner-radius changes;
- no sex/mate/genealogy/migration/predator/species framework;
- no population target.
