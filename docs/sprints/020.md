# Sprint 020 — Promote validated grazer old-age hazard

Status: **active** (#116)

## Goal

Promote the exact Sprint 019 gradual mortality hazard into authoritative runtime behind a default-off switch, without retuning the curve or adding per-creature lifespan state.

## Exact curve

No old-age mortality before age 12.

For age >= 12:

`pAnnual(age) = min(0.50, 0.01 * 2 ^ ((ageYears - 12) / 3))`

Daily conversion:

`pDaily = 1 - (1 - pAnnual) ^ (1 / daysPerYear)`

The chance is keyed by world seed, creature ID, authoritative day, and a private salt. There is no hard maximum age.

## Runtime seam

One public config switch only:

`grazerOldAgeMortalityEnabled: false`

Curve parameters remain private mechanics.

Daily order:

`environment → grazer action/aging/starvation → humans → day increment → grazer old-age hazard → grazer reproduction → settlements`

Old-age removal reuses the existing typed grazer death lifecycle with `cause: old_age`. Starvation remains earlier and distinct.

## Persistence

Snapshot schema remains **v11**.

The switch is already covered by existing config snapshot/restore. `worldFromSnapshot()` merges defaults, so an older v11 snapshot with no mortality key restores to `false`. No per-creature old-age state exists to migrate.

## Required verification

- default/false path behaviorally inert;
- no old-age death before 12y;
- deterministic keyed old-age death with typed history and zero sequential RNG use;
- starvation cannot double-kill as old age;
- enabled save/load continuation exact;
- old v11 missing config key restores disabled;
- Sprint 019 60-year seeds `1/4/9` × founders `20/100/200` population/birth fingerprint reproduced under authoritative runtime;
- full CI + smoke green.

## Guardrails

No lifespan field, max-age endpoint, hazard tuning, reproduction/resource/encounter retuning, population target, generic mortality framework, new species, predators, or social/mate state.
