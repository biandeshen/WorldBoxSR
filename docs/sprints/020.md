# Sprint 020 — Promote validated grazer old-age hazard

Status: **complete — authoritative default-off mortality implemented** (#116)

## Goal

Promote the exact Sprint 019 gradual mortality hazard into authoritative runtime behind a default-off switch, without retuning the curve or adding per-creature lifespan state.

## Exact curve

No old-age mortality before age 12.

For age >= 12:

`pAnnual(age) = min(0.50, 0.01 * 2 ^ ((ageYears - 12) / 3))`

Daily conversion:

`pDaily = 1 - (1 - pAnnual) ^ (1 / daysPerYear)`

The chance is keyed by world seed, creature ID, authoritative day, and a private salt. There is no hard maximum age.

## Runtime seam

One public config switch only:

`grazerOldAgeMortalityEnabled: false`

Curve parameters remain private mechanics.

Daily order:

`environment → grazer action/aging/starvation → humans → day increment → grazer old-age hazard → grazer reproduction → settlements`

Old-age removal reuses the existing typed grazer death lifecycle with `cause: old_age`. Starvation remains earlier and distinct, and a starved creature is removed before the old-age pass so it cannot double-die.

## Persistence

Snapshot schema remains **v11**.

The switch is covered by existing config snapshot/restore. `worldFromSnapshot()` merges defaults, so an older v11 snapshot with no mortality key restores to `false`. No per-creature old-age state exists to migrate.

## Verification

All required semantics are pinned by `tests/grazer_old_age.test.js`:

- default/false path is behaviorally inert;
- no old-age death before 12y;
- a known keyed age-30 death occurs on the exact authoritative day without sequential RNG use;
- `creature.died` records typed cause `old_age` and age;
- starvation remains distinct and cannot double-kill;
- enabled save/load continuation is exact;
- old v11 snapshots without the new config key restore disabled;
- the authoritative 60-year seeds `1/4/9` × founders `20/100/200` runtime reproduces the exact Sprint 019 population/birth fingerprint.

The pinned year-60 populations are:

| Founders | seed1 | seed4 | seed9 |
| ---: | ---: | ---: | ---: |
| 20 | 93 | 109 | 128 |
| 100 | 11 | 69 | 130 |
| 200 | 26 | 62 | 124 |

and births are respectively `199/260/249`, `48/148/185`, and `55/111/170`.

Full test suite and smoke pass with the heavy multi-seed regression enabled.

## Decision

The validated gradual hazard is now authoritative but **default-off**. No mortality tuning or framework expansion is justified.

Default worlds still contain zero creatures; existing v11 snapshots retain previous behavior unless the new switch is explicitly enabled.

## Next gate

With grazing, reproduction, carrying pressure, encounter recovery, and natural turnover now all validated as one coherent opt-in ecology, the next evidence question is no longer another grazer mechanic.

Before making animals part of ordinary generated worlds, test deterministic **natural grazer initialization/activation** as research only: can a small initial fauna sustain bounded multi-generation ecology across a broader landscape-seed sample without scripting a target population? Do not add predators or make default worlds non-empty until that gate passes.
