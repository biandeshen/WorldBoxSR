# Sprint 011 — Measure grazer carrying pressure before reproduction

Status: **active** (#95)

## Goal

Characterize long-horizon survival and vegetation pressure across explicit grazer densities before adding any reproduction rule or default animals.

Sprint 010 proved the one-way loop:

`vegetation regrowth → grazer grazing → biomass depletion → regrowth`

but a 2-year 0/5/20 density response is not enough to design a self-sustaining population.

## Stage 1 bracket

Use creature-only 24×24 worlds with default grazer parameters:

- landscape seeds `1/4/9`;
- initial densities `5/20/100/300`;
- 5-year horizon;
- deterministic initial placement across vegetation-rich land cells rather than one-tile piling;
- no humans.

Checkpoint at years 1/2/3/5 and track minimum vegetation utilization at 30-day cadence.

## Metrics

For each seed/density:

- living grazers;
- creature deaths;
- creature meals;
- meals per initial grazer;
- total vegetation / capacity / utilization;
- minimum observed vegetation utilization;
- occupied creature cells;
- sequential world RNG before/after.

## Interpretation

The purpose is to locate a legible resource-limited regime:

- if all densities survive with high vegetation, grazer energy/resource scale is too weak to justify reproduction;
- if high densities partially or fully die while lower densities persist, the model has an interpretable carrying-pressure bracket;
- if responses are discontinuous/chaotic, refine the threshold before births.

## Reproduction gate

Do not implement reproduction in Stage 1.

A future off-by-default reproduction spike is allowed only if this sprint can state a transparent control target, such as:

- births require adequate grazer condition / local vegetation;
- starvation/resource collapse suppresses births;
- population remains bounded across multiple landscape seeds;
- sequential human RNG remains isolated;
- vegetation does not pin permanently near zero.

## Guardrails

- no human behavior changes;
- no default creatures;
- no reproduction code in Stage 1;
- no predators/species framework;
- no settlement/territory interaction;
- no daily trajectory retention;
- temporary probes removed before merge;
- negative outcomes are recorded, not parameter-searched away.
