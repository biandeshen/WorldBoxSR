# Sprint 010 — First endogenous ecology loop

Status: **active** (#93)

## Goal

Add one minimal creature, the **grazer**, whose survival consumes renewable vegetation. Default worlds remain creature-free; grazers enter only through explicit god spawning in v0.

The target loop is:

`vegetation regrowth → grazer hunger/movement/eating → vegetation depletion → regrowth`

## Identity boundary

Creatures use a typed ID domain:

- `world.creatures`;
- `nextCreatureId`;
- history entity kind `creature`.

They do **not** consume human `nextEntityId` values. Human IDs feed keyed-random behavior, so inserting animal IDs into that stream would cause hidden human-history changes unrelated to ecology.

Spawn history uses `creatureIds`, not the human-oriented generic `entityIds` payload currently understood by `historyForHuman`.

## Grazer v0 state

Each grazer stores:

- creature ID;
- `kind: creature`;
- `species: grazer`;
- x/y;
- ageDays / bornDay;
- hunger;
- health;
- alive / causeOfDeath.

No reproduction or social state exists.

## Behavior

Each tick:

1. age and hunger increase;
2. if hungry and current vegetation is edible, eat;
3. otherwise a hungry grazer moves one passable step toward the locally highest vegetation and then tries to eat;
4. a non-hungry grazer may take a keyed-random passive step;
5. starvation damages health; health can recover while well-fed;
6. health <= 0 records `creature.died` with cause `starvation` and removes the creature from the living collection.

All movement choices use keyed randomness / stable ordering and consume **no sequential world RNG**.

## Spawn command

`spawn_creature` accepts only `species: grazer` in v0.

- explicit in-bounds land tile;
- bounded count;
- validate before command-ID allocation;
- deterministic creation with no RNG;
- `god.spawn_creature` records typed `creatureIds`.

This is an extensible command shape, not a species registry/framework.

## Isolation from humans

Grazers do not:

- consume food;
- attack humans;
- join settlements;
- own territory;
- reproduce;
- read human/lineage/union state.

Default worlds contain no creatures. Existing human/settlement history must remain unchanged when no creature is spawned, regardless of grazer config values.

## Persistence / metrics / history

- snapshot schema bump for creature state and config;
- typed `historyForCreature()`;
- current-reference resolution for `entityKind: creature`;
- metrics for living creatures/grazers, creature meals, creature deaths;
- deterministic save/load continuation.

## Evidence gate

After core CI, run a controlled density study with identical vegetation worlds and explicit grazer counts. Require:

- more grazers cause stronger vegetation depletion over the same horizon;
- vegetation recovers when grazing pressure is absent;
- no sequential RNG consumption from grazer behavior;
- default/no-grazer human history stays identical.

Do not add default animals or reproduction in this sprint.

## Client only after core/evidence

If the ecology loop passes, add a minimal `Spawn grazer` tool plus simple render/inspect/history selection. No art pass.

## Non-goals

- no reproduction;
- no predator/prey;
- no combat;
- no settlements/territory;
- no food consumption;
- no multiple-species registry;
- no AI behavior tree;
- no fire/season coupling;
- no default animal population.
