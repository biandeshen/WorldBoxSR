# Sprint 023 — Test down-only area scaling for compact grazer founders

Status: **active** (#122)

## Goal

Repair the compact-map failure from Sprint 022 with one structural founder-count rule, without turning initialization into a carrying-capacity controller.

Research-only: no runtime initializer/default-fauna change.

## Pre-registered rule

Use the validated 24×24 reference density and scale **down only** by total map area:

`founders = min(10, max(2, floor(10 * width * height / (24 * 24))))`

Square reference values:

- 16×16 → 4;
- 18×18 → 5;
- 20×20 → 6;
- 22×22 → 8;
- 24×24 → 10;
- larger worlds remain capped at 10.

The rule is derived from the validated reference geometry, not fitted to failed seeds or passable-land counts. No formula parameter may change in this sprint.

## Fixed initializer and ecology

Placement/age semantics remain exactly those from Sprint 021. Reproduction `0.001`, gradual old-age mortality, radius-3 partner discovery, radius-1 vegetation eligibility, grazing/starvation/movement/cooldown semantics, and sequential-RNG isolation remain unchanged.

## Stage 1

`16×16`, seeds `1..30`, 120 years, **4 founders**.

Every world must remain non-extinct, end >=10, have >=5 births in years101–120, have replacement-parent reproduction, remain below passable-land-cell count, preserve sequential RNG, and avoid permanent vegetation collapse.

If any world fails, stop. Do not tune the rule.

## Stage 2

Only after Stage 1 passes, test `18×18 / 20×20 / 22×22 / 24×24`, seeds `1..20`, 120 years, using formula counts `5 / 6 / 8 / 10`.

The same gate applies. 24×24 is a reference control.

## Boundary

Passing only resolves founder-count mechanics over the tested compact/reference size range. Runtime activation remains a separate product/compatibility gate.
