# Sprint 008 — Add a behavior-neutral vegetation biomass layer

Status: **completed** (#89 / #90)

## Goal

Add the first richer world-resource layer beyond generic food: **renewable vegetation biomass** distributed by the existing moisture/fertility landscape, while preserving all current human and settlement behavior.

This sprint creates environmental substrate. It intentionally adds no consumer yet.

## Why this sprint existed

Sprint 007 established a clean god-intervention/lifecycle/history seam. Adding more powers immediately would mostly increase feature count while the world substrate still had one generic renewable resource.

The terrain generator already produced coherent moisture fields, but moisture was mostly inert after world creation. Vegetation turns that existing field into authoritative environmental state that future systems can interact with:

- animals/grazing;
- fire or lightning;
- wood/building;
- ecology and disturbance/recovery.

None of those consumers were added here.

## Authoritative tile state

Every tile now carries:

- `vegetationCapacity`;
- `vegetation`.

Ocean tiles remain exactly zero.

For passable land, v0 uses intentionally transparent formulas:

- `vegetationCapacity = 2 + 8 * moisture`;
- `initial vegetation = vegetationCapacity * (0.35 + 0.65 * fertility)`.

Both moisture and fertility already existed before this feature. World creation adds **no new sequential RNG draw**.

## Regrowth

Authoritative config now includes:

`vegetationRegrowthPerDay = 0.006`

Daily vegetation regeneration:

- happens independently of food regeneration;
- adds `vegetationRegrowthPerDay * (0.2 + 0.8 * moisture)` on passable land;
- clamps at `vegetationCapacity`;
- forces ocean biomass to zero;
- consumes no RNG.

## Behavior-neutrality result

Humans and settlements do not read vegetation in v0.

A dedicated 20-year semantic test runs two otherwise identical worlds with vegetation regrowth set to `0` vs `1`. The vegetation trajectories diverge, while all of the following remain exactly equal:

- RNG state;
- human state;
- food state;
- settlement / territory state;
- lineage state;
- parental-union state;
- causal history;
- counters and stable IDs.

The independent seed45 long-run demographic regression also remains green.

Therefore vegetation is an authoritative world layer without becoming a hidden demographic parameter.

## Serialization and metrics

Snapshot schema advances from **v8 → v9** because tile/config authoritative state changed.

Save/load continuation preserves vegetation exactly.

World summary now reports:

- total vegetation;
- total vegetation capacity;
- vegetation utilization.

Metrics remain derived-only.

## Quality result

Final feature CI: **166/166 tests + smoke**.

Dedicated tests cover:

- deterministic moisture-gradient capacity / initial biomass;
- wetter-land capacity ordering;
- ocean zero-state;
- bounded daily regeneration;
- no food or RNG mutation from vegetation regeneration;
- 20-year whole-simulation behavior neutrality under divergent vegetation trajectories;
- snapshot v9 save/load continuation;
- read-only vegetation metrics;
- multi-decade vegetation invariants;
- existing seed45 demographic history.

## Non-goals preserved

- no forest/grassland/dryland taxonomy yet;
- no human or settlement vegetation consumption;
- no wood inventory or buildings;
- no animal grazing;
- no fire/lightning interaction;
- no seasons;
- no climate simulation;
- no rendering requirement.

## Handoff

The world now has a second renewable authoritative resource layer and an unused environmental causal substrate.

A future system should consume or disturb vegetation only if it creates a useful loop. Do not add a catalog of resource types merely because the tile schema supports more fields.

The strongest next candidates are endogenous ecology (a minimal creature that consumes vegetation) or a genuinely different disturbance such as lightning/fire. Choose by causal value, not by feature checklist.
