# Sprint 008 — Add a behavior-neutral vegetation biomass layer

Status: **active** (#89)

## Goal

Add the first richer world-resource layer beyond generic food: **renewable vegetation biomass** distributed by the existing moisture/fertility landscape, while preserving all current human and settlement behavior.

This sprint creates environmental substrate. It does not add a consumer yet.

## Why now

Sprint 007 established a clean god-intervention/lifecycle/history seam. Adding more powers immediately would mostly increase feature count while the world substrate still has one generic renewable resource.

The terrain generator already produces coherent moisture fields, but moisture is mostly inert after world creation. Vegetation turns that existing field into authoritative environmental state that future systems can interact with:

- animals/grazing;
- fire or lightning;
- wood/building;
- ecology and disturbance/recovery.

None of those consumers belong in this sprint.

## Authoritative tile state

Every tile gains:

- `vegetationCapacity`;
- `vegetation`.

Ocean tiles remain exactly zero.

For passable land, v0 uses intentionally transparent formulas:

- `vegetationCapacity = 2 + 8 * moisture`;
- `initial vegetation = vegetationCapacity * (0.35 + 0.65 * fertility)`.

Both moisture and fertility already exist before this feature. No new world-generation RNG draw is allowed.

## Regrowth

Add `vegetationRegrowthPerDay` to authoritative config.

Daily vegetation regeneration:

- happens independently of food regeneration;
- adds `vegetationRegrowthPerDay * (0.2 + 0.8 * moisture)` on passable land;
- clamps at `vegetationCapacity`;
- leaves ocean at zero;
- consumes no RNG.

## Behavior-neutrality contract

Humans and settlements must not read vegetation in v0.

Therefore this sprint must preserve:

- founder human identity/placement/sex/hunger RNG sequence;
- food initialization and food regeneration;
- movement/eating/reproduction/death;
- settlement/territory history;
- seed45 demographic sentinel;
- causal event ordering apart from snapshot/config schema metadata.

The snapshot schema must bump because tile/config authoritative state changes.

## Metrics

World summary adds:

- total vegetation;
- total vegetation capacity;
- vegetation utilization.

Metrics remain derived-only.

## Tests

- deterministic capacity and initial biomass;
- wetter otherwise-equivalent land has higher capacity;
- ocean capacity/biomass remain zero;
- daily regrowth obeys moisture factor, clamps at capacity, and consumes no RNG;
- food values are untouched by vegetation regeneration;
- snapshot/save-load preserves vegetation exactly;
- vegetation metrics are read-only;
- existing seed45 long-run demographic regression remains unchanged;
- invariants and smoke remain green.

## Non-goals

- no forest/grassland/dryland taxonomy yet;
- no human or settlement vegetation consumption;
- no wood inventory or buildings;
- no animal grazing;
- no fire/lightning interaction;
- no seasons;
- no climate simulation;
- no rendering requirement.

## Handoff

A future system may consume or disturb vegetation only if it creates a useful causal loop. Do not add a catalog of resources merely because the tile schema now supports a second one.
