# Sprint 009 — Lightning as a vegetation disturbance

Status: **active** (#91)

## Goal

Add one deterministic exact-tile `lightning` intervention that connects the Sprint 007 god-action/lifecycle seam to the Sprint 008 vegetation substrate.

The loop is intentionally small:

`lightning → local human death + vegetation reset → deterministic vegetation recovery`

## Semantics

For any in-bounds tile:

- capture vegetation before strike;
- set tile vegetation to zero;
- collect living humans on the exact tile in stable ID order;
- record one `god.lightning` event with command cause, tile, before/after biomass, and target IDs;
- kill those targets through shared human lifecycle with cause `lightning` and causal reference to the god event;
- remove dead humans from current entities;
- consume no RNG.

Food, food capacity, terrain, passability, biome, ownership, and settlement lifecycle are untouched.

Ocean lightning is accepted and remains a zero-target / zero-biomass intervention event.

## Recovery

No burning/fire state is added. Existing vegetation regeneration is the only recovery mechanism.

A struck land tile should therefore naturally recover biomass over later ticks according to moisture and configured vegetation regrowth.

## Client

Add `Lightning` to the existing tool selector. Primary click applies it; Shift has no special lightning meaning. Inspect controls remain unchanged.

## Tests

- vegetation reset only on exact tile;
- food/terrain invariance;
- stable human target ordering and `lightning` death cause;
- resolvable `god.lightning → human.died` causal chain;
- parental-union mortality bookkeeping;
- no off-cadence settlement mutation;
- zero RNG consumption;
- ocean accepted no-op event;
- deterministic biomass recovery after strike;
- save/load continuation;
- client tool contract;
- all existing long-run human regressions remain green when lightning is not invoked.

## Non-goals

- no wildfire spread;
- no burning tile state;
- no damage/health framework;
- no radius or AOE;
- no terrain or food destruction;
- no meteor/plague;
- no generic power registry.

## Handoff

Only introduce fire-state/spread infrastructure if this exact-tile disturbance establishes a useful environmental intervention and a spread model can preserve unrelated RNG/history semantics.
