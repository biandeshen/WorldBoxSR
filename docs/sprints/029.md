# Sprint 029 — Test encounter-safe compact grazer founder placement

Status: **active** (#134)

## Goal

Test one narrow placement-only intervention for genuine compact founder encounter/establishment failures, after Sprints025–028 rejected synthetic scalar persistence gates.

No runtime/default-fauna behavior changes in this sprint.

## Fixed ecology

16×16 creature-only worlds, founders `2/4`, existing keyed founder ages `[0,6y]`, reproduction `0.001`, gradual old-age mortality enabled, partner radius3, local vegetation radius1 threshold0.50, and all existing movement/grazing/starvation/health/cooldown semantics unchanged.

## Paired placement arms

Both arms use the exact same ranked top32 vegetation-rich passable-cell pool.

### Baseline

Select the first N ranked cells, matching the existing research initializer.

### Encounter-safe

1. Find the lexicographically earliest ranked pair within Chebyshev radius3; if none exists, fall back to the first two ranked cells.
2. Add founders by repeatedly selecting the highest-ranked unselected candidate within radius3 of the already selected set.
3. If no connected candidate remains, fall back to the highest-ranked unselected candidate.

Founder IDs/order and keyed ages remain identical between arms. Coordinates are the only causal change.

## Matrix

Seeds `1..60` × founders `2/4` × baseline/intervention = **240 worlds**, each to year300.

## Direct outcomes

No synthetic persistence threshold. Record:

- initial radius3 pair edges/components/isolates;
- initial local vegetation context;
- time to first birth and births by year20;
- total/replacement-parent births;
- actual extinction/time-to-extinction or year300 censoring;
- starvation vs old-age deaths;
- minimum vegetation utilization;
- max living population;
- sequential RNG fingerprint.

Paired summaries per count report rescued, harmed, both-extinct/both-alive, zero-birth extinction counts, and first-birth changes.

## Decision

Advance this placement only if:

- founders2: rescued > harmed and zero-birth establishment extinctions decrease;
- founders4: harmed <= rescued;
- sequential RNG is unchanged;
- harms are audited rather than averaged away;
- there is no evidence of a systematic new early resource-collapse failure caused by concentration.

If not, reject. Do not tune radius, candidate pool, count, ages, or ecology here.
