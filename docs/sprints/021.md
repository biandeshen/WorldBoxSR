# Sprint 021 — Validate natural grazer initialization

Status: **active** (#118)

## Goal

Test whether a small deterministic founder population can turn the now-complete opt-in grazer mechanics into robust natural fauna across a broader landscape sample before ordinary generated worlds receive animals.

Research-only: no runtime initializer/default-world change in this sprint.

## Fixed authoritative ecology

- reproduction chance `0.001`;
- gradual old-age mortality enabled;
- partner-search radius 3;
- each parent's local vegetation radius 1 / threshold 0.50;
- current hunger, starvation, movement, cooldown, vegetation, and keyed-random semantics;
- no population target;
- no sequential RNG.

## Pre-registered initialization

- sort passable tiles by initial vegetation descending, then y/x;
- use the 32 richest passable cells;
- place founders round-robin across those cells;
- assign deterministic keyed age in `[0, 6 years]` from seed + future creature ID + a dedicated initialization salt;
- otherwise use normal grazer defaults.

## Stage 1

24×24 creature-only worlds:

- seeds `1..12`;
- initial counts `10 / 20 / 40`;
- 60 years.

Advance the **smallest** count that passes all 12 landscapes:

- no extinction;
- year60 population >= 10;
- >=5 births in years41–60;
- replacement-parent reproduction present;
- maximum population <300;
- sequential RNG unchanged.

No extra counts may be searched in this sprint.

## Stage 2

If Stage 1 selects a candidate, run that exact initializer/count unchanged on seeds `1..30` for 120 years.

Every world must remain non-extinct, end >=10, retain >=5 births in years101–120, have replacement-parent reproduction, stay below 300 living grazers, preserve sequential RNG, and avoid permanent vegetation collapse.

## Decision

Passing this sprint only proves a natural initializer is technically/ecologically credible. Whether ordinary worlds become fauna-on by default remains a separate product/compatibility decision.

No predators, second species, human/settlement interaction, art work, runtime initializer, or ecology retuning in Sprint 021.
