# Sprint 013 — Add default-off authoritative grazer reproduction v0

Status: **completed** (#100)

## Goal

Promote the exact Sprint 012 condition/resource-gated pair mechanism into authoritative runtime state while keeping reproduction disabled by default.

## Runtime scope

Only the proven minimum is implemented:

- `grazerBirthChancePerEligiblePairPerDay`, default `0`;
- persisted per-grazer `lastBirthDay` cooldown state;
- maturity at one world year;
- health >= 0.95;
- hunger <= existing grazer hungry threshold;
- radius-1 local vegetation utilization >= 0.50;
- one-world-year successful-birth cooldown for both parents;
- stable adjacent pair selection;
- keyed pair/day randomness;
- one age-0 child on a parent tile;
- typed `creature.born` history with newborn subject and both parent creature causes/IDs;
- dedicated `creatureBirths` counter and world metric.

No sex, mate bond, creature genealogy, gestation, litter, predator, species registry, or global population controller was introduced.

## Daily ordering

Reproduction runs after the day’s vegetation regrowth, grazer actions, human update, and day increment. This preserves the Sprint 012 probe semantics: eligibility sees post-feeding/post-health state, keyed chance uses the advanced world day, and a newborn does not act until the following tick.

## Persistence

Snapshot schema advances from v10 to v11. v10 loads migrate deterministically with:

- `lastBirthDay: null` on existing creatures;
- `creatureBirths: 0`;
- reproduction chance supplied by the new default `0`.

Loading a migrated v10 world therefore cannot silently enable reproduction.

## Verified gates

The implementation test suite proves:

- one forced-success eligible pair creates exactly one age-0 grazer;
- the birth event has a typed newborn subject and both parent creature causes/IDs;
- child and both parents can retrieve the same birth through existing `historyForCreature()` queries;
- sequential `world.rng` is unchanged by reproduction;
- immaturity, hunger, low health, low local vegetation, cooldown, and lack of an adjacent eligible partner each suppress birth;
- successful parents enter cooldown immediately;
- with birth chance `0`, cooldown state is behaviorally inert;
- v10 snapshots migrate deterministically to inert v11 reproduction state;
- enabled reproduction survives exact save/load continuation including cooldowns, events, counters, IDs, and future keyed behavior;
- 10-year seeds `1/4/9` regressions reproduce the Sprint 012 qualitative envelope: 20-founder worlds grow while vegetation stays abundant, while 200-founder worlds remain below their starting population after early bounded births;
- default creature-free worlds remain creature-free.

Full normal CI and smoke passed on the implementation branch before closeout.

## Decision

Authoritative grazer reproduction v0 is accepted **only as an explicitly enabled mechanic**. The project still does not seed creatures by default and the reproduction probability default remains zero.

The next ecology question should not be predators or a species framework. Before default animals are considered, the grazer life cycle still lacks natural turnover: age is tracked but low-pressure grazers do not currently die of old age. That should be measured and resolved before treating the ecology as a complete self-sustaining default loop.
