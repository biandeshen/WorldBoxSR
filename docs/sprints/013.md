# Sprint 013 — Add default-off authoritative grazer reproduction v0

Status: **active** (#100)

## Goal

Promote the exact Sprint 012 condition/resource-gated pair mechanism into authoritative runtime state while keeping reproduction disabled by default.

## Runtime scope

Only the proven minimum is allowed:

- `grazerBirthChancePerEligiblePairPerDay`, default `0`;
- persisted per-grazer `lastBirthDay` cooldown state;
- maturity at one world year;
- health >= 0.95;
- hunger <= existing grazer hungry threshold;
- radius-1 local vegetation utilization >= 0.50;
- one-world-year successful-birth cooldown for both parents;
- stable adjacent pair selection;
- keyed pair/day randomness;
- one age-0 child on a parent tile;
- typed `creature.born` history with both parent creature causes/IDs;
- dedicated creature-birth counter.

No sex, mate bond, creature genealogy, gestation, litter, predator, species registry, or global population controller is introduced.

## Persistence

Snapshot schema advances from v10 to v11. v10 loads migrate deterministically with:

- `lastBirthDay: null` on existing creatures;
- `creatureBirths: 0`;
- reproduction chance supplied by the new default `0`.

## Gates

Before merge:

- forced-success birth and typed parent/child history;
- rejection for immaturity, hunger, health, local vegetation, cooldown, and missing adjacent partner;
- default-off cooldown state is behaviorally inert;
- v10 → v11 deterministic migration;
- enabled save/load continuation is exact;
- reproduction consumes no sequential RNG;
- multi-seed low-density growth and overloaded boundedness remain consistent with Sprint 012;
- full normal CI + smoke pass;
- default worlds still contain zero creatures.
