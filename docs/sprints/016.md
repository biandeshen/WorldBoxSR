# Sprint 016 — Promote grazer partner encounter radius 3

Status: **active** (#107)

## Goal

Promote only the partner-search geometry proven by Sprint 015 from Chebyshev radius 1 to radius 3.

## Runtime change

Authoritative grazer reproduction now uses a private `REPRODUCTION_PARTNER_RADIUS = 3` constant when selecting an eligible second parent.

Everything else remains unchanged:

- each parent's local vegetation test still uses radius 1;
- birth chance and default-zero behavior;
- one-year maturity;
- health >= 0.95;
- hunger <= existing grazer hungry threshold;
- one-year successful-birth cooldown;
- stable deterministic pair ordering;
- keyed pair/day randomness;
- one newborn on parent A's tile;
- typed birth history and counters;
- daily ordering;
- snapshot schema v11;
- default worlds contain zero creatures.

No public interaction-radius config/framework is introduced.

## Gates

Before merge:

- an otherwise eligible pair at Chebyshev distance 3 creates exactly one birth;
- an otherwise eligible pair at distance 4 cannot reproduce;
- the existing eligibility rejection suite treats lack of a partner within radius 3 as failure;
- sequential RNG remains unchanged;
- default-off behavior and enabled save/load continuation remain exact;
- the multi-seed 10-year regression stays bounded and resource-limited;
- full normal CI + smoke pass.

## Guardrails

No lifespan/senescence, mate bond, sex, genealogy, gestation, migration, population target, predators, species framework, human coupling, or snapshot change in this sprint.

After this seam is authoritative, natural turnover can be re-researched against the corrected encounter geometry rather than the rejected radius-1 ecology.
