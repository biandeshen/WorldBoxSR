# Sprint 015 — Isolate low-density grazer reproductive encounter recovery

Status: **active** (#105)

## Goal

Resolve the low-density reproductive Allee effect diagnosed in Sprint 014 before revisiting natural senescence.

Sprint 014 showed that adding natural mortality creates a two-stage trap:

`resource depletion suppresses births → mortality reduces population → vegetation recovers → sparse spatial distribution suppresses adjacent encounters`

The local resource gate is useful and stays unchanged. Sprint 015 changes only partner encounter distance.

## Research-only comparison

Temporary reproduction logic preserves the Sprint 012/013 conditions exactly:

- age >= 1 world year;
- health >= 0.95;
- hunger <= existing grazer hungry threshold;
- each parent radius-1 local vegetation utilization >= 0.50;
- one-world-year successful-birth cooldown;
- keyed birth chance `0.001` per eligible pair/day;
- stable deterministic pair selection;
- one age-0 child on a parent tile;
- no sequential RNG.

The only experimental variable is maximum partner-search Chebyshev radius: `1 / 2 / 3`.

A wider search radius is encounter opportunity only. It does not move animals, create a mate bond, change either parent's local-resource test, or imply a social/residential entity.

## Diagnostic turnover stressor

Use the same temporary deterministic `18–36` year keyed lifespan from Sprint 014 solely to expose the recovery bottleneck. It is not an accepted runtime lifespan.

## Stage 1 matrix

Creature-only 24×24 worlds:

- seeds `1/4/9`;
- founder densities `100/200`;
- founders age 2 years;
- 45-year horizon;
- partner radii `1/2/3`;
- fixed birth chance `0.001` and local vegetation threshold `0.50`.

Track living population, births, starvation/old-age deaths, founder extinction, replacement-generation births, vegetation, eligible pair supply, occupied cells, and sequential RNG isolation.

## Decision gate

Prefer the smallest radius that:

- persists through founder turnover on all three landscapes rather than merely delaying extinction;
- continues replacement-generation reproduction after founders disappear;
- still suppresses births in the depleted phase via the unchanged resource gate;
- remains bounded and does not pin vegetation near zero;
- preserves landscape/resource feedback;
- consumes no sequential RNG.

If radius 2 works, do not advance radius 3 as runtime just because it also works. If neither works, stop and test a different causal encounter mechanism rather than tuning birth chance, resource threshold, or lifespan.
