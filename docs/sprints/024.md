# Sprint 024 — Diagnose compact grazer founder-count and spatial sensitivity

Status: **active** (#124)

## Goal

Stop proposing scalar scaling formulas and diagnose why compact 16×16 worlds respond non-monotonically to founder count.

Research-only: no founder count, formula, placement, runtime initializer, or default-fauna behavior can be promoted from this sprint.

## Fixed mechanics

Use 16×16 creature-only worlds and the exact Sprint 021 vegetation-rich placement/age family. Keep reproduction `0.001`, gradual old-age mortality, partner radius3, local vegetation radius1/threshold0.50, all grazing/starvation/movement/cooldown semantics, and sequential-RNG isolation unchanged.

## Stage 1 — bounded response surface

Seeds `1..30` × founder counts `2 / 4 / 6 / 8 / 10` × 120 years.

The five counts are diagnostic points, not a search. No other count may be tested.

For every run record the existing terminal ecology gate plus initialization descriptors:

- passable land count/components/largest component;
- fraction of land in components reached by founders;
- founder distinct cells and spatial bounding box;
- radius3 founder pair graph edges/components/largest component/isolates;
- mean nearest-founder Chebyshev distance;
- mean founder radius1 vegetation utilization.

Report count-level pass/extinction rates, per-seed passing-count sets, transition/non-monotonic patterns, and exact responses for seeds2/6/7/10/24.

If one count passes all 30 seeds it is only a candidate for a separate unseen-seed validation issue. It must not be promoted here.

If no count passes all 30, scalar founder count is insufficient and the topology evidence should determine whether spatial seeding deserves the next causal test.

## Optional Stage 2

Only if Stage 1 remains causally ambiguous, collect 10-year trajectories for the first ten seed numbers whose pass/fail status changes across the pre-registered counts. Do not change counts or mechanics.
