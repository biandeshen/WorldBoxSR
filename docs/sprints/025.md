# Sprint 025 — Characterize cycle-aware persistence on compact grazer worlds

Status: **active** (#126)

## Goal

Determine whether 16×16 worlds that fail the current year-120 terminal ecology gate are truly non-viable or are merely sampled during a recoverable low phase of a long resource-demography cycle.

This sprint changes evaluation only. It cannot change founder count, founder placement, ecology parameters, runtime initialization, or default-fauna behavior.

## Horizon and measurements

Run every case from year0 to year240. Checkpoint every 10 years.

Record:

- living population;
- total births and rolling 20-year births;
- old-age vs starvation deaths;
- vegetation utilization;
- reproduction-eligible grazers and radius3 eligible pair edges;
- whether the old terminal gate would pass at each checkpoint >= year40;
- minimum population after year20;
- longest continuous span after year20 with population <10;
- longest continuous zero-birth span after year20;
- recoveries from population <10 back to >=10;
- extinction timing;
- old-gate pass/fail flip count;
- first old-gate pass after year120 for cases that failed at year120;
- exact sequential RNG fingerprint.

Do not retain daily trajectories.

## Questions

1. Do the eight alive year120 failures recover after year120?
2. How long can a recoverable trough remain below population10 or the five-birth/20y continuation threshold?
3. Are any alive year120 failures actually deterministic precursors to later extinction?
4. How often does the old gate flip pass/fail in worlds that remain viable?
5. Can true extinction be separated from cyclic troughs using trajectory/rolling-window facts without introducing a target population?

## Decision rule

This is diagnostic only.

### Terminal gate is phase-sensitive

If most/all alive-at-120 failures later recover and passing controls also flip the old gate across checkpoints, retire the single-terminal-sample gate for compact initializer research. Define a cycle-aware research gate from the observed recovery/zero-birth span envelope.

### Terminal weakness is predictive

If most alive-at-120 failures proceed to extinction without meaningful recovery, retain terminal weakness as a useful warning and return the next causal experiment to initialization/spatial seeding.

### Mixed result

If some recover and some later die, preserve the split and identify the smallest additional trajectory observable needed. Do not tune mechanics.

Any future gate must remain descriptive: no global target/controller and no requirement that coherent natural cycles remain continuously above a fixed population floor.
