# Sprint 027 — Validate sustained zero-birth stall as compact non-recovery signal

Status: **active** (#130)

## Goal

Test whether sustained generational inactivity—continuous absence of grazer births—is a useful compact-world non-recovery signal after Sprint026 falsified low population duration as a trigger.

This sprint changes evaluation only. Runtime ecology, founder placement/count semantics, and default-world behavior remain unchanged.

## Fixed ecology

Use the existing 16×16 research setup:

- vegetation-rich top32 / round-robin founder placement;
- keyed founder ages `[0,6y]`;
- reproduction chance `0.001`;
- gradual old-age mortality enabled;
- partner radius3;
- each parent's local vegetation radius1 threshold0.50;
- unchanged movement/grazing/starvation/health/cooldown;
- sequential RNG isolation.

## Fresh validation set

Seeds `31..60` × founders `2/4/6/8/10` = **150 worlds**, year0→300.

No seed in this matrix was used in Sprints021–026 compact initialization/evaluation studies.

## Exact hypothesis

After year20, maintain continuous time since the most recent grazer birth.

A still-living world becomes **generationally stalled** after exactly **40 continuous years with zero births**.

Population size is descriptive only and never triggers this rule.

After a stall flag, a later **meaningful generational recovery** occurs at a 10-year checkpoint when:

- world is non-extinct; and
- rolling previous-20-year births `>=5`.

Any flagged world that later meaningfully recovers is a false non-recovery signal and rejects the hypothesis.

Extinction itself is direct non-persistence and needs no 40-year wait.

## Stage 2 — censoring only

If any world is alive at year300, has been flagged, and has not recovered, extend only those exact cases unchanged to year420. Do not add worlds or alter the 40-year rule.

## Measurements

Record derived summaries only:

- extinction timing;
- first zero-birth-40y flag;
- meaningful recovery after flag;
- false-signal / censored state;
- longest zero-birth duration;
- longest population<10 duration (descriptive only);
- vegetation and reproduction-eligible/pair opportunity at 10-year checkpoints for flagged cases;
- rolling20 births at checkpoints;
- sequential RNG fingerprint.

## Decision

The hypothesis passes only if there are **zero false non-recovery signals** through the pre-registered observation/extension horizon and all censored cases are resolved/reported.

A pass would validate a conservative *research evaluation signal* only. It is not a runtime population controller, biological mortality/reproduction rule, or guarantee that fauna must survive forever.

Any false signal rejects the hypothesis. Do not search another duration or add population/resource conditions in this sprint.
