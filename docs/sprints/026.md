# Sprint 026 — Validate compact 40-year recovery envelope on unseen cases

Status: **active** (#128)

## Goal

Independently test the exact 40-year compact recovery-envelope candidate derived in Sprint 025. This sprint validates evaluation only and cannot alter ecology, founder count, placement, runtime initialization, or default-fauna behavior.

## Fixed ecology

Use the exact Sprint 024/025 16×16 setup: vegetation-rich top32/round-robin founders, keyed founder ages `[0,6y]`, reproduction `0.001`, gradual old-age mortality enabled, partner radius3, each parent's local vegetation radius1 threshold0.50, unchanged movement/grazing/starvation/health/cooldown, and sequential RNG isolation.

## Stage 1 — unseen-to-derivation set

Seeds `17..30` × founders `2/4/6/8/10` = **70 worlds**, year0→300.

These exact worlds were not part of Sprint025's 18-case threshold-derivation set. The matrix is fixed before results.

## Exact candidate rule

After year20, maintain continuous durations for:

1. living population `<10`;
2. no grazer births.

While the world is still non-extinct, it becomes **candidate stalled** the first day when either duration reaches exactly **40 continuous years**.

The 40-year value is fixed and may not change in this sprint.

After a stall flag, a later **meaningful recovery** occurs only at a 10-year checkpoint where both:

- living population `>=10`;
- rolling previous-20-year births `>=5`.

Any flagged world that later meaningfully recovers is a **false non-persistence signal** and rejects the candidate.

Extinction is directly non-persistent and does not require a stall flag.

## Stage 2 — censoring only

A world that is alive at year300, has been flagged, and has not meaningfully recovered is censored. If any exist, extend only those exact cases unchanged to year420. No threshold/world/mechanic changes.

## Measurements

For each world retain derived summaries/checkpoints only:

- extinction year;
- first 40y low-pop / zero-birth flag;
- first candidate stall day and cause;
- first meaningful recovery after flag;
- false-signal boolean;
- longest low-pop / zero-birth span;
- final population and births;
- 10-year population / rolling20 births / vegetation / reproduction-eligible / pair-edge checkpoints;
- sequential RNG fingerprint.

## Decision

The candidate passes only with **zero false non-persistence signals** through the pre-registered Stage1/Stage2 horizon. Censored cases must be reported.

A pass validates 40 years only as a conservative *research waiting envelope for non-extinct compact troughs*. It is not a runtime biological rule, population target, or controller.

Any false signal rejects 40 years. Do not search another threshold in this issue.
