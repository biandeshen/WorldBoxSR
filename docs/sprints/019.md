# Sprint 019 — Test gradual age-dependent grazer mortality hazard

Status: **active** (#114)

## Goal

Test one gradual mortality shape after Sprints 017–018 showed that neither hard keyed lifespan bands nor founder-age heterogeneity can robustly preserve grazer turnover at carrying pressure.

Research-only first pass: no runtime old-age death/config/state/event/schema change.

## Fixed authoritative ecology

Keep unchanged:

- reproduction partner search radius 3;
- each parent's local vegetation radius 1 with threshold 0.50;
- birth chance `0.001`;
- maturity / health / hunger / one-year successful-birth cooldown / stable pairing;
- keyed randomness and separate creature identity;
- no global population target;
- no sequential RNG.

All founders start at age 2 so mortality **shape** is the only changed causal variable relative to Sprint 017.

## Pre-registered hazard

No research old-age death before age 12.

For age >= 12:

`pAnnual(age) = min(0.50, 0.01 * 2 ^ ((ageYears - 12) / 3))`

Daily conversion:

`pDaily = 1 - (1 - pAnnual) ^ (1 / daysPerYear)`

Use keyed daily chance `(world.seed, creature.id, world.day, dedicated salt)` after grazer action/day increment and before authoritative reproduction.

Reference annual rates: age12 1%, age15 2%, age18 4%, age21 8%, age24 16%, age27 32%, age30+ 50% cap.

No hard maximum age. Do not tune curve parameters in this issue.

## Stage 1

60-year screen:

- 24×24 creature-only worlds;
- seeds `1/4/9`;
- age-2 founders `20/100/200`;
- authoritative reproduction enabled at `0.001`.

Track population, max/min, births, replacement-parent births, final-20-year births, starvation/research-old-age deaths, founder turnover, vegetation pressure/recovery, age summaries, and sequential RNG.

## Stage 2 gate

Only extend the unchanged curve to 120 years if every Stage-1 world remains genuinely multi-generational: no extinction/tiny terminal tail, replacement-parent births occur, and births continue in the final 20 years.

## Promotion gate

Runtime mortality is not considered until the same curve:

- persists across all landscapes at low density and carrying pressure;
- avoids the cohort cliff seen with hard lifespans;
- keeps vegetation resource-limiting without weakening resource/reproduction gates;
- remains bounded without a population target;
- preserves causal starvation vs old-age distinction;
- consumes no sequential RNG.

A Stage-1 failure ends this curve. No parameter search in Sprint 019.
