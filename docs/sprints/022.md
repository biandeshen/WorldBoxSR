# Sprint 022 — Test whether natural grazer founders need map-size scaling

Status: **active** (#120)

## Goal

Test the simpler activation hypothesis first: the validated 10-grazer population may be a founder seed rather than a target density, so it may not need to scale with map size at all.

Research-only. No runtime initializer or default-world change in this sprint.

## Fixed initializer and ecology

Use the exact Sprint 021 initializer unchanged:

- 10 founders;
- passable tiles sorted by initial vegetation descending, then y/x;
- round-robin placement over the 32 richest passable cells;
- keyed founder age in `[0,6y]` using the same initialization salt;
- normal grazer defaults otherwise.

Enable authoritative reproduction `0.001` and gradual old-age mortality. Keep radius-3 partner discovery, radius-1 vegetation eligibility, hunger/starvation/movement/cooldown/resource semantics, and sequential-RNG isolation unchanged.

## Stage 1

Sizes `16×16 / 24×24 / 32×32 / 48×48`, seeds `1..12`, 60 years.

Every size/seed world must remain non-extinct, end >=10, have >=5 births in years41–60, have replacement-parent reproduction, remain below its passable-land-cell count, preserve sequential RNG, and avoid permanent vegetation collapse.

If all 48 worlds pass, fixed 10 advances unchanged. If any fails, stop: no alternate count or scaling formula may be tried in Sprint 022.

## Stage 2

Only after a complete Stage-1 pass, run the same 48 worlds to 120 years under the same gate with births measured in years101–120.

## Decision boundary

Passing proves founder-count scaling is unnecessary over the tested 16–48 square size range. It still does not make fauna default-on; activation compatibility remains a separate product gate.

No population target, ecology retuning, predators, second species, human/settlement interaction, client expansion, or scaling-formula search.
