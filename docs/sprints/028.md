# Sprint 028 — Characterize pre-extinction grazer birth-stall sensitivity

Status: **active** (#132)

## Goal

Measure whether a single zero-birth duration can separate persistent compact grazer cycles from terminal generational failure before proposing any shorter threshold.

This is derivation/diagnostic only. No threshold is accepted here and runtime ecology/initialization remain unchanged.

## Fixed cohort

Re-run Sprint027's exact 16×16 matrix:

- seeds `31..60`;
- founders `2/4/6/8/10`;
- vegetation-rich top32 / round-robin placement;
- keyed founder ages `[0,6y]`;
- reproduction `0.001`;
- gradual old-age mortality enabled;
- partner radius3;
- local vegetation radius1 threshold0.50;
- unchanged movement/grazing/starvation/health/cooldown;
- no sequential RNG;
- year0→300.

This cohort is now explicitly a **derivation set**. Any candidate produced from it must later be validated on new seeds.

## Measurements

Track exact birth timing and retain derived summaries:

- extinction year;
- birth count;
- last birth year;
- late-extinction terminal birthless span from the later of year20 / last birth to extinction;
- longest completed inter-birth gap after year20 while alive;
- survivor right-censored gap from last birth to year300;
- longest population<10 duration as context only;
- exact sequential RNG fingerprint.

Early extinctions before year20 are reported separately and are not used to derive a post-year20 warning duration.

## Decision

Compare late-extinction terminal gaps against persistent-world completed/right-censored gaps.

- If distributions overlap, reject a single-duration birth-gap classifier and stop threshold work.
- If a clean separating interval exists, record the most conservative candidate boundary as **derived only** and validate it later on a fresh seed set.
- Do not add population/resource conditions post hoc.
- Do not change ecology, founder count, or placement.

## Cleanup

Temporary probes/test overrides are removed before merge. Preserve evidence and project truth only.
