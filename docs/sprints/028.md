# Sprint 028 — Characterize pre-extinction grazer birth-stall sensitivity

Status: **complete — single-duration classifier rejected** (#132)

## Goal

Measure whether a single zero-birth duration can separate persistent compact grazer cycles from terminal generational failure before proposing any shorter threshold.

Derivation/diagnostic only; runtime ecology/initialization remain unchanged.

## Cohort

Sprint027's exact 16×16 matrix was re-run: seeds `31..60` × founders `2/4/6/8/10` = 150 worlds, year0→300.

## Result

- survivors: **118**;
- early extinctions before year20: **1**;
- late extinctions: **31**.

Late-extinction terminal birthless spans:

- min **0.42y**;
- median **21.49y**;
- max **29.98y**.

Persistent-world observed birth gaps (max completed/right-censored):

- min **7.91y**;
- median **17.88y**;
- max **22.71y**.

The distributions overlap strongly: **16/31** late extinctions have terminal birthless spans no longer than the maximum persistent gap. There is no clean separating interval.

## Decision

- reject a single-duration zero-birth persistence classifier;
- stop choosing shorter durations from this cohort;
- do not add population/resource conditions post hoc;
- keep ecology/count/placement/runtime behavior unchanged;
- use direct paired causal outcomes for future initializer experiments, especially genuine initial encounter/establishment failure.

Permanent evidence: `docs/experiments/2026-08-24-grazer-birth-stall-sensitivity.md`.

## Cleanup

Temporary probe/test override are removed before merge. Default worlds remain creature-free.
