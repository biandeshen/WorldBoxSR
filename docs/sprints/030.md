# Sprint 030 — Fresh-validate encounter-safe compact grazer placement

Status: **active** (#136)

## Goal

Fresh-validate the exact frozen Sprint029 encounter-safe placement candidate on compact seeds not used in derivation.

Validation only: no algorithm, founder count, age, ecology, runtime initializer, or default-fauna changes.

## Fixed mechanics

16×16 creature-only worlds, founders `2/4`, existing keyed ages `[0,6y]`, reproduction `0.001`, gradual old-age mortality, partner radius3, each parent's local vegetation radius1 threshold0.50, and all movement/grazing/starvation/health/cooldown semantics unchanged.

## Frozen arms

Both arms use the same top32 passable cells ranked by initial vegetation desc, then y/x.

- baseline: first N ranked cells;
- encounter-safe: exact Sprint029 algorithm — earliest ranked radius3-connected pair, then highest-ranked unselected cells connected within radius3 to the selected set, with ranked fallback only when no connected candidate remains.

Founder IDs/order and keyed ages remain identical between arms.

## Fresh matrix

Seeds `61..120` × founders `2/4` × baseline/intervention = **240 worlds**, year0→300.

## Direct outcomes

Record initial founder graph/context, first birth, births by year20, total/replacement births, actual extinction/time-to-extinction, starvation vs old-age deaths, vegetation minimum, max population, and exact sequential RNG fingerprint.

## Validation rule

The frozen candidate passes only if:

- founders2 intervention extinctions <= baseline;
- founders2 zero-birth extinctions do not increase;
- founders4 intervention extinctions <= baseline;
- combined rescued > harmed;
- no systematic starvation/resource-collapse tradeoff;
- all harmed cases are audited;
- sequential RNG remains unchanged.

Any failed criterion rejects the candidate. Do not tune algorithm/count/ecology in this sprint.

A pass makes the placement eligible only for a separate explicit natural-initializer implementation/compatibility decision. Default worlds remain creature-free.

## Cleanup

Temporary probe/test override are removed before merge. Preserve evidence and project truth only.
