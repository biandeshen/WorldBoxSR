# v0.7.0 canonical demo — Scenario Builder & Sharing

This is the release QA path for the public browser build. It verifies the v0.7 promise:

> **I can compose a deterministic Scenario, share/import the exact same start, Run it, Replay it, or Fork it into a different deterministic Scenario.**

## Open the product

Public demo: `https://biandeshen.github.io/WorldBoxSR/play/`

Canonical release configuration:
- Phaser renderer;
- seed `45`;
- Mode **Sandbox**;
- current supported 24×24 / 40-year showcase-ready startup;
- ordinary deterministic simulation remains the only world authority.

## 5-second Scenario gate

A first-time viewer should immediately identify:
- the world map as the primary surface;
- topbar **＋ Scenario** and **⇪ Recipe** controls;
- normal Seed / Mode / World / Play / View / Time controls;
- God Powers remaining ordinary gameplay tools outside Scenario Setup.

Scenario tooling should feel like a compact layer over the world, not a file manager or dashboard.

## Run boundary

Click **Run Scenario**.

Confirm:
- Setup editor disappears;
- ordinary controls and God Powers return;
- a small `SCENARIO · 3` identity badge remains;
- the authoritative start is unchanged at the Run boundary;
- later Play/Time/God Power use changes the world but not the frozen Recipe.

Replay/Fork later operate on this Recipe identity, not on a live snapshot.

## Copy Link gate

Open **⇪ Recipe** and click **Copy Link**.

Expected behavior:
- the Recipe card identifies `Portable trio · 3/32 actions`;
- the generated URL remains on the public Phaser `/play/` path;
- query state contains exactly a portable `scenario=` Recipe token plus any unrelated state that is explicitly preserved;
- canonical player links do not force `renderer=legacy`;
- the token is unpadded base64url;
- the text area shows the same link if clipboard access is unavailable.

The canonical automated gate independently decodes the token and requires it to equal the exact canonical Recipe JSON.

## Fresh shared-browser gate

Open the copied link in a genuinely fresh tab/profile.

Expected exact state:
- `Portable trio` Recipe identity;
- `SCENARIO · 3` badge;
- paused day `14400`;
- authoritative fingerprint **`7f07ed67`**;
- no second ordinary warmup happens underneath/after the imported Scenario.

This is deterministic reconstruction through Recipe materialization, not snapshot transfer.

## JSON Export / Import gate

### Export

From **⇪ Recipe**, click **Export JSON**.

Confirm:
- downloaded JSON is the canonical Recipe only;
- the same canonical JSON is visible in the text area;
- no raw world snapshot/debug state is exported.

Canonical automated filename: `Portable-trio.worldboxsr-scenario.json`.

### Import

In another ordinary fresh Phaser world:
1. open **⇪ Recipe**;
2. paste the canonical JSON;
3. click **Import JSON**.

Expected result:
- paused exact source day `14400`;
- fingerprint **`7f07ed67`**;
- exact normalized Recipe;
- current URL is not silently rewritten by JSON Import.

An invalid/impassable Recipe must be rejected before replacing the current authority. The canonical negative gate uses a Wolf placement at `(18,12)` and requires truthful `impassable tile 18,12` feedback while the previous Scenario remains intact.

## Replay gate

Starting from the fresh shared source:
1. use ordinary **Time → 1 day** and Play so the world advances;
2. use the existing **Meteor** God Power to make the divergence obvious;
3. pause;
4. open **⇪ Recipe** and click **Replay Scenario**.

Canonical automated evidence:
- dirty source fingerprint: `dfbad7ff`;
- frozen source Recipe remains byte-identical;
- Replay restores exact source fingerprint **`7f07ed67`** at day `14400`;
- stale Event Card / Focused Story / Inspector / selection presentation is cleared;
- the source Recipe is still the same canonical `Portable trio`.

Replay means **rematerialize the Recipe start**. It is not timeline rewind, event replay or snapshot restore.

Confirm:

- top badge is `FORK · 3`;

## Release question

After publication verification, the release boundary is:

> Can I create a small Scenario, send the Recipe to someone else, trust that we start from the exact same authoritative world, run divergent histories, Replay the deterministic start, and Fork it into a distinct deterministic Scenario without snapshots, a hidden second world model or raw engine tooling?

A yes closes v0.7. No terrain editor, cloud/workshop, live savegame, rules DSL, timeline rewind or new simulation mechanic belongs in the release handoff.
