# v0.1.0 reproducible demo — A Living World

This demo has two parts:

1. a **deterministic headless run** that is easy to reproduce exactly;
2. an **interactive client walkthrough** that shows the watch / inspect / intervene loop.

## 1. Deterministic headless run

Requirements: Node.js 22+.

Run the same 100-year world twice:

```bash
npm run sim -- --seed 42 --years 100 --population 30 --width 32 --height 32 --json
```

The same release + seed + arguments must produce the same final JSON summary. This is the quickest user-facing check that a world can be reproduced.

For a compact progress view instead of final JSON:

```bash
npm run sim -- --seed 42 --years 100 --population 30 --report-every 10
```

You should see population, cumulative births/deaths, average age and food utilization at 10-year intervals, followed by a final summary and recent deaths when present.

## 2. Watch the client

Start the local server:

```bash
npm run dev
```

Open:

```text
http://127.0.0.1:8080
```

Use seed `42` and press **Reset**.

The client provides:

- Pause / resume;
- simulation speeds from 1 day/frame to 1 year/frame;
- pan with drag and zoom with the mouse wheel;
- right-click / Alt-click / tap to inspect world targets;
- world-history and selection-history timelines.

For a quick long-horizon watch, choose **1 year/frame** and let the world run for several decades.

## 3. Inspect history

Right-click / Alt-click a visible human, tile or settlement to inspect it. Use the history scope selector to switch between:

- **World** history;
- **Selection** history.

Select timeline entries to inspect recorded causal events rather than inferred story labels.

## 4. Intervene

The v0.1 god-tool selector includes:

- **Spawn human**;
- **Spawn grazer**;
- **Erase humans**;
- **Lightning**.

Primary-click applies the selected tool. Shift-click spawns 10 for the spawn tools.

A grazer spawned in v0.1 is an explicit intervention: default worlds do not auto-create fauna, and natural-fauna activation remains a v0.2 topic.

## 5. Reproduce

For exact reproducibility, use the headless run in step 1. Interactive worlds are deterministic given the same seed **and the same sequence/timing of user interventions**, but clicking at different simulation days is intentionally a different history.

Resetting the client to the same seed reproduces the same initial world.

## 6. Release verification

Before tagging v0.1.0, the release candidate must also pass:

```bash
npm test
npm run smoke
```

The full suite covers deterministic simulation contracts, invariants, history causality, commands/god tools, client contracts, ecology behavior, persistence/save-load behavior and long-run regressions.
