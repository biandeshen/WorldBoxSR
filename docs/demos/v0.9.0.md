# v0.9.0 canonical demo — World Feel & Public Alpha

This is the release QA path for the v0.9 public browser build.

Primary release promise:

> **Opening WorldBoxSR puts the living world first: large, readable, animated, visibly changing, recoverable, and usable across desktop and touch.**

## Open the product

Public demo: `https://biandeshen.github.io/WorldBoxSR/play/`

Canonical desktop review:
- Phaser renderer;
- seed `45`;
- ordinary 1440×900 browser surface;
- default supported 24×24 showcase world.

## 5-second desktop gate

A first-time viewer should see the world itself as the dominant surface, not a small map surrounded by dead UI space.

Check that:
- the world fills most of the vertical viewport beneath floating HUD chrome;
- terrain remains readable under territory borders;
- settlements visibly differ in physical footprint;
- current units/warbands remain above map-history traces;
- Inspector and Power Dock remain contextual overlays rather than exclusive camera rectangles.

The canonical composition calculation renders the 672×672 world at roughly 864×864 on 1440×900, versus roughly 718×718 before the v0.9 world-first change.

## Civilization readability gate

Without opening raw simulation data, the map should communicate several existing facts:
- larger settlements have larger building/field/street footprints;
- polity frontiers can be traced visually;
- warband strength appears as a small soldier formation while exact strength remains readable;
- marching armies expose a short direction cue and target-settlement reticle;
- recent real battles may leave low-depth historical traces;
- abandoned settlements read as ruins, not as population-zero villages;
- occupation/recent-rebellion states use compact truthful identity cues when those states are present.

These are projections of existing authority. They must not imply fake pathfinding, crater/fire terrain, former ruin population, loyalty or resistance strength.

## Living-world motion gate

Observe moving Humans, Grazers and Wolves. Existing movement interpolation should drive bounded gait motion without creating separate action state. Active settlements may show subtle banner/hearth ambience.

With Reduce Motion enabled, presentation motion must reduce rather than increase. A stricter system reduced-motion preference remains authoritative over the local preference.

## God Power recovery gate

Use the existing Meteor → Rain path on passable inhabited land.

Required truth:
1. Meteor creates its existing authoritative damage and vegetation removal;
2. a low-key recent impact-site memory can remain while the real footprint is ecologically depleted;
3. Rain restores vegetation through the existing authoritative command;
4. after the footprint returns to vegetation capacity, the impact memory disappears;
5. no crater, fire, elevation change or invented rebuilding state is implied.

The full browser suite continues to verify the existing v0.4 God Power causal path.

## Local Session persistence gate

For an ordinary Sandbox/Living Ecology world:
1. open Inspector → `Session`;
2. use **Save now**;
3. advance or otherwise change the ordinary world;
4. use **Restore**;
5. restored authority must install paused;
6. seed/preset UI must match the save;
7. **Clear** removes the local slot without changing the running world.

Automated Node evidence freezes exact snapshot round-trip and continuation semantics. Corrupt, unsupported or quota-failed storage must fail atomically.

Scenario boundary:
- an active/shared/frozen Scenario Recipe disables ordinary local-world Save/Restore;
- Scenario continues to use Recipe / Replay / Fork identity;
- a startup Scenario link is never overridden by local autosave.

## Mobile 430×820 gate

On a coarse touch surface, verify the compact HUD and the production input contract:
- tap = selected power / Scenario placement;
- hold ≈460 ms = Inspector;
- drag >5 px = pan;
- two-finger pinch = zoom;
- core controls remain reachable without the old overflowing desktop topbar.

Frozen real-Chromium pinch evidence at implementation freeze:
- zoom `0.5863095× → 1.2703374×`;
- midpoint drift `0.00000854` world px;
- humans/command/event remain exactly `44 / 9 / 174` before, during and after pinch;
- after both fingers release, one fresh tap resumes normally at `45 / 10 / 175`.

Long-hold proof separately verifies that Inspector opens while command/human/event counts remain unchanged through release.

## Recovery and accessibility gate

Renderer failure must expose explicit recovery actions rather than silently creating a second world/render state. The player can retry or choose the compatibility renderer intentionally.

Accessibility controls:
- **Reduce Motion** changes presentation only;
- **Mute Sound** prevents God Power audio from starting;
- both preferences stay local and do not mutate world authority.

## Performance gate

`npm run pages:build` / `npm run pages:check` must preserve the dedicated Phaser vendor chunk and the checked <300 KB minified app-chunk budget.
