# WorldBoxSR v0.1.0 — A Living World

v0.1.0 is the first real project release: a deterministic, watchable world-simulation vertical slice.

The release is intentionally bounded. It demonstrates a world that can generate reproducible history from simple rules; it does not attempt to solve every future ecology, civilization or god-game system.

## Shipped

### Deterministic simulation core

- seeded, serializable randomness;
- fixed-tick world state;
- deterministic save/load continuation;
- invariants, regressions, long-run simulation tooling and performance baselines.

### World and resources

- procedural terrain fields and land/ocean constraints;
- renewable food;
- renewable vegetation biomass;
- causal disturbance/history support.

### Humans and society

- hunger, movement, eating, aging, reproduction and death;
- ancestry/lineage history;
- parental-union historical evidence;
- settlements, home bias, abandonment and territory;
- explicit preservation of rare coherent natural settlement extinction instead of hidden rescue rules.

### Grazer ecology

- typed grazer creatures;
- explicit spawning;
- vegetation grazing and starvation;
- default-off local reproduction with radius3 partner discovery and radius1 resource eligibility;
- default-off gradual old-age mortality;
- deterministic creature history and inspection.

Grazer ecology exists in v0.1, but **automatic natural-fauna initialization is not a supported release feature yet**.

### Client and history

- lightweight world rendering;
- pan/zoom camera;
- tile/human/settlement/grazer inspection;
- world and selection history timeline;
- recorded causal event detail.

### God tools

- Spawn human;
- Spawn grazer;
- Erase humans;
- Lightning.

### Developer/research tooling

- headless simulation CLI;
- Simulation Lab batch/parallel workflows;
- deterministic/regression/invariant tests;
- metrics and benchmark tooling.

## Important design decisions preserved

- lineage is ancestry, not household;
- parental union is historical shared-birth evidence, not spouse state;
- carrying capacity is evidence, not a runtime population target;
- coherent extinction/collapse is allowed when causality and invariants are sound;
- broad settlement food storage and generic survival rescue were tested and rejected;
- hard grazer lifespan bands were rejected in favor of a gradual keyed mortality hazard;
- compact natural-fauna research showed strong path dependence, so v0.1 does not claim a universal auto-fauna initializer.

## Known limitations / deferred work

### v0.2 — Living Ecology

- explicit natural-fauna activation/preset semantics;
- declared support matrix for natural initialization;
- supported initializer validation and ecology observability;
- no requirement that every seed keep fauna alive forever.

### v0.3 — Civilizations

- kingdoms/polities;
- rulers/succession;
- diplomacy, war, conquest and rebellion;
- richer territory/ownership visualization.

### v0.4 — God Game

- meteor;
- plague;
- broader intervention UX/history feedback.

### Later

- richer onboarding and presentation;
- multi-species ecology only when new mechanics justify it;
- packaging/public-alpha polish.

## Reproduce the release demo

See `docs/demos/v0.1.0.md`.

Core commands:

```bash
npm test
npm run smoke
npm run sim -- --seed 42 --years 100 --population 30 --json
npm run dev
```

## Version policy

From v0.1 onward, the project uses finite release boundaries documented in `docs/ROADMAP.md`. Interesting research no longer blocks a release indefinitely unless it exposes correctness, determinism, data-integrity or promised-experience failures.
