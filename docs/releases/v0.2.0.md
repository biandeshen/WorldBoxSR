# WorldBoxSR v0.2.0 — Playable World

v0.2.0 is the first release whose primary success criterion is **player-visible game quality**, not additional hidden simulation breadth.

The deterministic world built in v0.1 remains authoritative. v0.2 puts a real browser-game presentation around it: a world that reads clearly at a glance, responds immediately to god powers, exposes settlement territory and causal history, and is continuously verified through the same public Pages path players use.

## Play online

`https://biandeshen.github.io/WorldBoxSR/`

Canonical release QA: `docs/demos/v0.2.0.md`.

## Shipped

### Phaser/Vite playable presentation

- Phaser 4.2.1 presentation over the existing deterministic JavaScript engine;
- Vite 8.1.0 development and production build;
- production GitHub Pages project-site path;
- browser rendering remains downstream of authoritative simulation state rather than becoming a second world model.

### A world that reads like a game

- deeper ocean/coast/land treatment and deterministic terrain texture;
- vegetation clusters, rocks and presentation-only water shimmer;
- recognizable miniature human and grazer forms instead of circles/squares;
- interpolated movement and lightweight condition/status cues;
- population-tiered settlement structures, fields, names, flags and abandoned-state treatment;
- subtle settlement-colored territory fill and ownership-change borders projected from authoritative `ownerSettlementId`.

### Camera and interaction

- responsive wide-screen composition that reserves room for the inspector and God Powers dock;
- pan, wheel zoom and deliberate world centering;
- persistent selection highlight for humans, grazers, settlements and tiles;
- moving selected entities keep their marker; disappeared entities clear rather than leaving stale presentation state.

### God-hand UX

- direct Human / Grazer / Erase / Lightning power dock;
- keyboard shortcuts and tile-sized target preview;
- truthful invalid-target feedback for land-only spawn powers;
- immediate spawn, erase and lightning visual effects;
- minimal generated Web Audio SFX for all four core powers;
- reduced-motion/reduced-flash profiles, including no lightning camera shake when reduced motion is requested.

v0.2 deliberately ships **without ambient sound or music**. Audio breadth is deferred until the core visual/game loop justifies it.

### Living-world feedback and history

- causal Chronicle remains the detailed authoritative history view;
- lightweight world-event pulse surfaces newly occurring settlement founding/abandonment events and rate-limited birth/death summaries;
- event cards use recorded history only and do not invent narrative facts;
- the canonical seed45 showcase has an executable deterministic 30-second product gate tied to the actual selected UI speed and Phaser step interval.

### Public development and product evidence

- public GitHub Pages playable demo;
- Codespaces browser development path;
- GitHub-hosted Simulation Console for deterministic headless runs;
- normal CI for tests, smoke and production build;
- real Chromium Visual QA that serves the production `/WorldBoxSR/` base path and retains fixed Phaser/legacy screenshots plus DOM/runtime logs.

## Product gates satisfied

### 5-second readability

A new viewer can identify terrain/water/vegetation, living units, named settlements/territory, pause/speed controls and God Powers without reading the README.

### 30-second autonomous-world change

`tests/showcase_30s_gate.test.js` reads the actual default `60 days` speed and actual `110ms` Phaser step interval, warms the canonical seed45 world to year40, and proves a player-readable settlement/birth/death pulse occurs within the resulting 30-second foreground pacing budget.

### Interaction

The four core powers have direct controls, truthful targeting, immediate visual feedback and SFX. Inspection leaves a persistent world-space selection marker.

### Determinism / truth

- existing deterministic/save-load/invariant suites remain authoritative;
- presentation interpolation, overlays, audio and effects do not mutate simulation truth;
- god actions alter simulation only through authoritative commands;
- the headless CLI and Simulation Lab remain available.

## Legacy renderer decision

The v0.1 Canvas renderer remains available in v0.2 at:

`https://biandeshen.github.io/WorldBoxSR/?renderer=legacy`

It exists only as A/B evidence and a migration regression escape hatch. v0.3 should retire it by default unless a concrete regression workflow still requires it.

## Known limits

v0.2 is a credible playable beginning, not a claim of WorldBox-level breadth or polish.

- presentation art is still prototype/programmatic rather than final bespoke production art;
- audio is intentionally minimal;
- settlements are not yet kingdoms/polities;
- there is no diplomacy, war, conquest or rebellion yet;
- there is no editor, rewind/replay product loop or broad ecosystem expansion in this release;
- coherent natural collapse/extinction remains allowed; no hidden survival controller was added for presentation convenience.

## What comes next

### v0.3 — Civilizations Rise

The next player-facing stage is civilization dynamics: polity/kingdom identity, rulers/succession, diplomacy, war/peace, conquest/rebellion and territory/history that visibly tells those stories.

Deeper multi-species ecology remains intentionally later (currently v0.6) so the project does not fall back into invisible research while the player-facing game is still growing.
