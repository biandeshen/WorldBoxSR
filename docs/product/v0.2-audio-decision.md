# v0.2 audio decision — feedback, not ambience

v0.2 ships a deliberately narrow audio layer:

- short generated Web Audio SFX for the four core god powers;
- no bundled audio assets and therefore no audio-asset licensing/provenance burden;
- no ambient world loop;
- no music;
- no simulation event narration.

The purpose is immediate input feedback, not atmosphere breadth. Ambient world sound and music remain later product work after the visual/god-hand loop is stable. Audio failure or browser autoplay policy must never change authoritative simulation behavior; sound is optional presentation feedback triggered only by an actual player power action.
