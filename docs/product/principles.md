# Product principles

## 1. Emergence over scripting
Prefer rules that create outcomes over authored outcome scripts.

## 2. Legible causality
A player should eventually be able to ask "why did this happen?" and get a useful answer from world history.

## 3. God, not micromanager
The player changes initial conditions and applies powers; the world should continue to act on its own.

## 4. History is a first-class output
The simulation should preserve major events so a 500-year-old city or dynasty can tell a coherent story.

## 5. Scale through cheap agents
Individual creatures use deterministic/utility-style behavior. LLMs, if ever used, sit above the hot simulation loop for narration or offline content generation.

## 6. Fast experiments
Any balance rule should be testable over many seeds without a graphical client.
