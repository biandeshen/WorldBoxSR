# v0.2 backlog — Playable World

v0.2 is the first executable slice of the master blueprint. It turns the public Pages build from a developer visualization into a coherent god-game experience **without rewriting the deterministic simulation core**.

Technical direction: `docs/decisions/0003-presentation-stack.md`. Finite release gate: #173. Canonical QA path: `docs/demos/v0.2.0.md`.

## Release promise

> Open the public demo and immediately see a living pixel world, understand the god controls, watch a visible change happen, and enjoy using the core powers.

## Mandatory product gates

### 5-second gate — PASS candidate

The fixed Chromium view exposes without documentation: terrain/water/vegetation, living units, named settlements and territory, pause/speed controls, and direct god powers. Final release review still checks the live Pages deployment.

### 30-second gate — PASS

`tests/showcase_30s_gate.test.js` reads the actual selected `60 days` option and actual `STEP_INTERVAL_MS = 110`, warms the authoritative seed45 world to year40, then proves a player-readable settlement/birth/death pulse occurs inside the resulting 30-second foreground pacing budget.

### Screenshot gate — PASS

Presentation-affecting PRs run the production Vite build in Chromium and retain fixed Phaser/legacy screenshots plus DOM/runtime logs.

### Interaction gate — PASS candidate

Direct power buttons, keyboard shortcuts, target preview, persistent inspected-selection feedback, visual effects and SFX are implemented. Final live Pages review remains the human-facing release check.

### Determinism gate — PASS

Full tests, save/load continuation, headless CLI and Simulation Lab remain authoritative; presentation layers mutate world state only through commands.

### Delivery gate — PASS

Vite production output is the GitHub Pages product path and has no local-only runtime dependency.

## Priority constraints until tag

- **No new non-correctness ecology research.**
- No kingdom/diplomacy/war, editor, replay, broad asset migration or generalized framework work.
- Only a P0/P1 bug discovered by final live Pages review may reopen implementation scope.

## Explicit non-goals

Matching WorldBox feature breadth; full civilizations/war; predators/food webs; universal natural fauna; trade/economy/culture/religion; world-builder/editor; replay/rewind; bespoke final art for every asset; mobile release commitment.

## Final release review

Before tagging v0.2, ignore commit/test counts and answer only:

> If someone opens `https://biandeshen.github.io/WorldBoxSR/` with no project context, does this now feel like the beginning of a game worth watching and touching?

If no, v0.2 is not complete. If yes and CI/Visual QA remain green, ship the checkpoint rather than reopening scope.
