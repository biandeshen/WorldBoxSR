# v0.2 backlog — Living Ecology

v0.2 begins **after v0.1.0 is tagged**. Its purpose is to turn the existing grazer subsystem from research/explicit-spawn capability into a coherent opt-in ecology feature.

## Release outcomes

- [ ] define natural-fauna activation semantics (explicit config/preset; default-on is not required)
- [ ] publish a supported map-size/preset matrix instead of requiring a universal initializer
- [ ] validate at least one natural grazer initialization path on every configuration claimed as supported
- [ ] keep founder placement/count/age logic deterministic and save/load compatible
- [ ] expose enough ecology inspection/metrics to explain births, deaths, resource pressure and extinction
- [ ] document that coherent natural extinction is allowed and is not automatically a failed initializer
- [ ] full regression/smoke/deterministic continuation gates green

## Research constraints

- no hidden survival controller or target population;
- no requirement that every seed preserve fauna forever;
- no more than three consecutive rejected hypotheses on the same non-correctness research thread before deferral;
- supported scope may exclude compact 16×16 auto-fauna if evidence does not justify a coherent initializer there;
- rejected Sprint029/030 encounter-safe placement may not be tuned incrementally without a genuinely new causal hypothesis;
- predators/second species are not v0.2 requirements.

## Candidate workstreams

### Activation and support policy

Decide whether v0.2 supports natural fauna only on a validated minimum world size (for example 24×24+) while smaller maps remain creature-free/explicit-spawn by default. This is a product boundary decision, not a claim that compact ecology is impossible.

### Natural initializer implementation

Promote only behavior that passes the declared support matrix. Preserve keyed ages, deterministic ordering, history causality and sequential-RNG isolation.

### Ecology observability

Make resource-demography cycles understandable in client/metrics without converting diagnostic labels into runtime control rules.

## Explicit non-goals

- kingdoms/diplomacy/war — v0.3;
- meteor/plague and power UX expansion — v0.4;
- universal auto-fauna across arbitrary sizes/seeds;
- multi-species food webs unless separately justified.
