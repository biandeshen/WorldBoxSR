# v0.7 backlog — Scenario Builder & Sharing

Release gate: #240. Version promise: **I can assemble a world setup, share/import its compact deterministic Scenario Recipe, reopen exactly the same starting world, then Run, Replay or Fork a different history.**

v0.7 productizes existing deterministic startup + commands. It is **not** the full terrain/world editor.

## Frozen release contract

A Scenario Recipe is deterministic startup input, never a live-world snapshot:

```json
{
  "kind": "worldboxsr-scenario",
  "version": 1,
  "name": "My scenario",
  "base": { "seed": 45, "preset": "sandbox" },
  "setup": [
    { "type": "spawn_human", "x": 8, "y": 8, "count": 1 },
    { "type": "spawn_creature", "species": "grazer", "x": 9, "y": 8, "count": 1 }
  ]
}
```

Frozen scope:
- base = current 24×24 / 40-year showcase-ready `sandbox | living_ecology` startup;
- setup = ordered Human / Grazer / Wolf placement only;
- max 32 setup actions, max 10 entities/action;
- name <=64 code units;
- canonical JSON <=8192 UTF-8 bytes;
- portable URL = unpadded base64url under exactly `scenario=`;
- malformed/unknown kind/version/preset/action/species/coordinates fail explicitly;
- Phaser is the Scenario product surface; Legacy remains comparison-only;
- no Recipe present remains byte-compatible with the existing ordinary startup.

## Truth boundaries

- Engine remains the only world truth.
- Recipe is deterministic startup input, never a live-state mirror.
- Recipe metadata/transport never enters world snapshots/history/RNG.
- Setup actions use existing authoritative commands only.
- Import replaces authority only after complete validation/materialization.
- Replay means rematerialize Recipe start, never timeline rewind.
- Fork creates a new editable Recipe without mutating imported/shared source identity.
- Existing ordinary startup without a Recipe remains a regression contract.
- Phaser is the v0.7 product surface; Legacy remains comparison-only.

## Explicit non-goals / stop rules

No terrain/biome/water/resource painter, live snapshot save-game UI, rules DSL/mod scripts, objectives/scoring, cloud/accounts/workshop backend, AI-generated authority, custom map sizes, new simulation mechanics, generic God-Power-to-Recipe conversion, short-link/compression protocol, timeline rewind/event-replay engine or Setup undo/remove stack.

## Product stop rule

v0.7 breadth is frozen around this loop:

**compose setup → share/import → exact same start → Run → Replay or Fork.**
