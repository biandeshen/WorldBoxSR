# v0.6 backlog — Living Ecology

Release gate: #223. Version promise: **I can watch animal populations and vegetation affect each other, and see predation change that living system.**

v0.6 is a supported-scenario ecology stage, not a universal ecosystem simulator. The deterministic engine remains the only ecology authority; presentation may explain recorded/current facts but never owns movement, birth, death, hunting, resources or population rescue.

## Supported release scope

- canonical map: **24×24**;
- Sandbox remains the compatibility-safe default;
- Living Ecology starts with exactly 10 validated natural Grazer founders;
- Grazer reproduction `0.001` + gradual old-age mortality are enabled only by Living Ecology; established Grazer movement/eating/starvation behavior is unchanged;
- exactly one additional predator species: **Wolf**;
- coherent extinction is allowed; no equilibrium, minimum-population or long-term coexistence promise;
- no hidden rescue/reseed/population target after initialization.
