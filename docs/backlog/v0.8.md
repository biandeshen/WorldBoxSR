# v0.8 backlog — Ruling Lines & Succession

Release gate: #255. Release handoff: #267.

Version promise:

> **I can watch a ruling bloodline inherit power across generations, see when that bloodline loses the throne, and follow the new ruling line in the same causal world history.**

v0.8 is one finite Civilization Depth stage. It is **not** economy + religion + technology + naval warfare in one release.

## Semantic boundaries

- `parental_union` stays historical co-parent identity; it does not become marriage, spouse, household, exclusivity, inheritance or political alliance.
- existing maternal `lineage` stays a lineage primitive; it does not become a noble house/dynasty.
- **ruling line** is political identity derived from explicit parent→child descent plus recorded polity succession.
- retained genealogy may resolve descendants after dead ancestors leave current humans; no second ancestry database is introduced.
- succession selection consumes no RNG.
- no eligible descendant preserves the existing deterministic open-selection fallback; no heir is manufactured.

## Product stop rule

v0.8 accepts no more behavior changes. Release-only work may only publish the frozen promise:

**ruler → explicit bloodline succession or line failure → readable political history.**

New product work resumes under a bounded v0.9 World Feel/Public Alpha plan after immutable v0.8 publication is verified.
