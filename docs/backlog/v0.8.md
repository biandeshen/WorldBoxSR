# v0.8 backlog — Ruling Lines & Succession

Release gate: #255.

Version promise:

> **I can watch a ruling bloodline inherit power across generations, see when that bloodline loses the throne, and follow the new ruling line in the same causal world history.**

v0.8 is one finite Civilization Depth stage. It is **not** economy + religion + technology + naval warfare in one release.

## Why this slice

WorldBoxSR already has:
- real-human polity rulers and deterministic succession/vacancy;
- authoritative parent IDs, child IDs, historical parental-union child records, lineage IDs and generations;
- causal ruler events and v0.5 Event Card / Focused Story / Watchlist / Rule-lens presentation;
- save/load and deterministic regression gates.

Prior research also says what **not** to do first:
- settlement shared-food-storage v0 was rejected despite mechanical correctness because broad demographic/spatial feedback produced causally misleading rescue effects;
- settlement scarcity is real but not a survival classifier;
- settlement decline/abandonment has heterogeneous demographic causes, so generic economic/rescue mechanics are not justified.

Ruling-line succession therefore offers more player-visible civilization depth with less speculative new authority.

## Semantic boundaries

### `parental_union` stays historical co-parent identity
It does not become marriage, spouse, household, exclusivity, inheritance or political alliance.

### `lineage` stays the existing maternal lineage primitive
It does not become a noble house/dynasty. Existing lineage v0 explicitly does not imply political organization, inheritance, class or co-residence.

### `ruling line` is political identity
Ruling-line continuation is determined from **explicit parent→child descent**, not from proximity and not by relabeling lineage/union.

Existing genealogy records may be used to reconstruct descendants after a ruler dies. No second ancestry database may be introduced.

## Frozen intended minimal succession policy

Founding appointment remains the current deterministic oldest-eligible-adult selection.

For later succession:
1. identify eligible living polity adults who are descendants of the current ruling-line founder;
2. prefer the nearest descendant generation from that founder;
3. within that generation preserve current age-descending, stable-ID ordering;
4. if no eligible descendant exists, use the current oldest-eligible polity-adult fallback;
5. an outsider fallback starts a new ruling line;
6. a vacancy remains truthful when no eligible adult exists; later filling applies the same policy;
7. succession selection consumes no RNG.

This is a small WorldBoxSR rule, **not** historical primogeniture/elective/agnatic succession simulation.

Required permanent resolver contracts:
- [ ] pure child adjacency derived from retained authoritative parent/child/parental-union facts;
- [ ] descendant distance from a founder ID without resurrecting dead humans;
- [ ] no invented spouse/household meaning;
- [ ] eligible descendants must also satisfy the current polity adult-membership requirements;

## Explicit non-goals

- no economy/trade/market/currency/storage system;
- no professions/jobs/classes;
- no marriage/spouse/household semantics or marriage diplomacy;
- no noble-house object graph, peerage/titles, claims or legitimacy scores;
- no elections or configurable succession-law UI;
- no claimant civil wars/usurpation mechanics added solely for this release;
- no religion/culture/technology tree;
- no boats/colonization/naval warfare;
- no broad diplomacy rewrite;
- no terrain/editor expansion;
- no AI-authored political facts;
- no fertility/migration/population rescue to manufacture heirs;
- no controller guaranteeing dynasty survival.

## Product stop rule

A v0.8 slice enters only if it directly improves:

**ruler → explicit bloodline succession or line failure → readable political history.**
